# 远程桌面操作步骤

用于通过 `examples/.agents/mcp.json` 中的 `desktop-agent-remote`、`tiny-image` 和 `examples/tiny-ocr-cli` 操作远程 Windows 桌面。目标任务示例：打开迅雷并点击顶部“新建”。

## 操作流程

1. **连接并确认桌面可用**
   - 启动配置里的 `desktop-agent-remote` 和 `tiny-image`，直接使用它们的桌面工具；不要用本机 macOS 应用列表判断远程电脑上有没有应用。
   - 先调用 `list_displays`、`screen_scale` 和 `list_windows`。检查远程主机可达且窗口/显示器信息正常。
   - 如果连接返回 `host is down`、超时或其他连接错误，先记录错误和时间到 `examples/record.md`，不要盲目操作或宣称已完成。

2. **先观察，再定位**
   - 调用 `capture_screen` 获取完整截图；保留截图 ID，并通过 `tiny-image_get_image` / `tiny-ocr-cli` 对同一张原图做 OCR。
   - 先查看窗口列表，再用 OCR 或清晰截图核对应用名称、按钮文字和目标位置。不要只凭图标颜色或记忆猜位置。
   - 如果应用不在前台，优先通过桌面名称选择：`win+d` 显示桌面 → 输入快捷方式的显示名称（如“迅雷”）→ `enter`。随后重新调用 `list_windows` 和 `capture_screen`，确认标题确为“迅雷”。不要用 `win+r` 直接运行显示名称；Run 框需要可执行文件名。

3. **换算并执行鼠标操作**
   - `capture_screen`/OCR 返回的坐标属于截图像素。鼠标注入坐标可能受远程桌面 DPI 比例影响；操作前读取 `screen_scale`，按当次返回值换算，不要直接照搬截图坐标。不要把具体坐标、屏幕尺寸或 DPI 数值写入记录。
   - 每次点击都严格按顺序调用 `mouse_move(x,y)`，再调用 `mouse_click(button:"left")`。`mouse_click` 只点当前光标位置，不会自动移动到目标。
   - 如果目标窗口已识别，先用其窗口 ID 调用 `focus_window`；若使用 `lock_window`，操作后记得 `unlock_window`。移动后先重新观察界面，确认指针落在目标控件上。

4. **点击并验证**
   - 在迅雷下载页，顶部工具栏的“+新建”和空白区域的“+新建任务”是两个不同控件。用户只要求点击“新建”时，点顶部工具栏按钮，不要替用户选择随后出现的任务类型。
   - 点击后重新截图并 OCR。看到“新建链接任务”/“新建 BT 任务”等菜单项，才算确认顶部“新建”已生效；不要因点击调用返回 `ok` 就认定完成。
   - 若界面没有变化，先检查截图、窗口焦点、DPI 换算和实际光标位置，再尝试一次；不要连续盲点。

## 常见问题与处理

| 问题 | 处理 |
| --- | --- |
| 本机找不到迅雷 | 这是远程 Windows 桌面任务；通过 MCP 窗口和截图检查远端，不要从本机启动。 |
| 远程主机不可达 | 记录到 `record.md` 并停止输入操作；服务恢复后再重试。 |
| 坐标误点到 Steam 或其他应用 | 重新读取当前 DPI 比例；把 OCR 原图坐标换算到鼠标坐标，先移动、核对位置，再点。 |
| OCR 命中错误的“迅雷” | 检查 `box` 所在区域；文字可能来自 Run 框而非桌面快捷方式。以截图位置及窗口标题交叉确认。 |
| 运行框提示找不到“迅雷” | 关闭 Run 框，回到桌面后用 `win+d` + 快捷方式显示名称选择；不要继续尝试裸应用名。 |
| 点击已返回成功但画面没变 | 成功响应只表示输入已发送；重新截图检查。确认当前指针实际落点、窗口是否聚焦、是否有模态窗口挡住。 |

遇到新的困惑、错误点击或服务故障时，把可复现步骤、错误文本和最终结果追加到 `examples/record.md`；不要写入具体位置、坐标、屏幕尺寸、DPI 数值或网络地址。
