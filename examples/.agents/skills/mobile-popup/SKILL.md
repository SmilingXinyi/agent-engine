---
name: mobile-popup
description: 识别并关闭手机应用中的广告弹窗，操作后确认弹窗消失且应用仍在前台。
---

从当前手机界面开始，先确认目标应用处于前台，再读取最新屏幕元素。

1. 识别明确的关闭、跳过、取消或 × 控件。使用最新元素 ref 或控件实际边界定位，避免凭印象点击。
2. 每次关闭操作后重新读取界面，确认弹窗消失且目标应用仍在前台。工具返回成功只代表操作已执行。
3. 存在倒计时时，等待结束并重新读取界面。没有可靠目标时停止并说明情况。
4. 遇到 INJECT_EVENTS 权限错误、登录或授权页面时停止。最多尝试 3 次关闭操作。

报告执行了什么操作，以及确认结果的依据。
